The language server can once again offer documentation hovers for reStructuredText roles.
Support for MyST roles is now also included, something which the ``v0.x`` implementation could never handle.

**Note:** Since roles are typically documented separately from their implementation this requires `esbonio` to be explicitly given the documentation associated with each role.
Therefore documentation hovers are only provided for core sphinx and docutils roles.
There are plans to (eventually!) provide a mechanism for sphinx extensions to contribute documentation (and other details) on the roles they provide.
